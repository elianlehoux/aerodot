# Seguridad

Aerodot es un sitio estático. No tiene cuentas.

Si encontrás una vulnerabilidad (por ejemplo un script inyectado, una dependencia comprometida o un token filtrado), escribinos a elian.developer@gmail.com. No abras un issue público con el detalle.

Incluí qué versión o commit miraste, qué haría falta para reproducirlo y el impacto que ves. Te respondemos cuando lo hayamos podido leer.

Un dato aeronáutico mal, una pregunta mal transcripta o una norma vieja no es un aviso de seguridad. Eso va en un issue, con la fuente.
